5 Step 2 — Prepare Terraform (Critical)

Backend issue: The repo defaults to an S3 backend that doesn't exist in your account. For a fast demo, switch to local backend.

Option A — Quick Local Backend (Recommended for demo)

Edit terraform/backend.tf to:

terraform {
  backend "local" {
    path = "terraform.tfstate"
  }
}

Option B — Keep S3 Backend

aws s3api create-bucket --bucket 8byte-tf-state-$(date +%s) --region us-east-1
# Then update backend.tf with your bucket name

Initialize:

cd terraform
terraform init -reconfigure

6 Step 3 — Deploy Infrastructure

terraform plan -var="db_password=DemoPass123!"
terraform apply -var="db_password=DemoPass123!" -auto-approve
Note: RDS Postgres takes 8–10 minutes. Use this time to explain architecture.

7 Step 4 — Get Outputs

terraform output

Expected outputs:

  • alb_dns_name — public URL
  • ecr_repository_url — for docker push
  • ecs_cluster
  • ecs_service
  • rds_endpoint

8 Step 5 — Build and Push Docker Image

export AWS_REGION=us-east-1
export ECR_URL=$(terraform output -raw ecr_repository_url)

aws ecr get-login-password --region $AWS_REGION | docker login --username AWS --password-stdin $ECR_URL

docker build -t 8byte-app:latest .
docker tag 8byte-app:latest $ECR_URL:latest
docker push $ECR_URL:latest
If Dockerfile is in a subfolder (e.g., ./app), adjust: docker build -t 8byte-app:latest ./app

9 Step 6 — Deploy to ECS

aws ecs update-service \
  --cluster $(terraform output -raw ecs_cluster) \
  --service $(terraform output -raw ecs_service) \
  --force-new-deployment \
  --region $AWS_REGION

10 Step 7 — Verify Live

# Open in browser
echo "http://$(terraform output -raw alb_dns_name)"

# macOS:
open http://$(terraform output -raw alb_dns_name)
# Linux:
xdg-open http://$(terraform output -raw alb_dns_name)
aws logs tail /ecs/8byte-app --follow --since 5m --region $AWS_REGION

11 Step 8 — Wire GitHub Actions (Optional Live Demo)

Add repository secrets: Settings → Secrets and variables → Actions

  • AWS_ACCESS_KEY_ID
  • AWS_SECRET_ACCESS_KEY
  • AWS_REGION = us-east-1
  • ECR_REPOSITORY = (from terraform output)
git add .
git commit -m "chore: trigger deploy"
git push origin main

12 Step 9 — Show Monitoring

Navigate: AWS Console → CloudWatch → Dashboards → 8byte-app-dashboard

  • ECS: CPUUtilization, MemoryUtilization
